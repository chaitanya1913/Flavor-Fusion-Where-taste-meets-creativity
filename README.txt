SAFFRON & SAGE — RESPONSIVE RESTAURANT WEBSITE

HOW TO OPEN
1. Extract the ZIP file.
2. Keep the folder structure unchanged.
3. Open index.html in Chrome, Edge, or Firefox.
4. The website runs locally; no installation is required.

FOLDER STRUCTURE
restaurant_website/
  index.html
  css/style.css
  js/script.js
  images/  (all local SVG food illustrations)

FEATURES
- Responsive desktop, tablet, and mobile layout
- Mobile navigation menu
- Menu category filters
- Booking form demo confirmation
- Local image assets; no image downloads required

NOTE
The booking form is a front-end demo only. It does not send reservations to a restaurant.
To receive real bookings, connect it to a backend or booking service.
